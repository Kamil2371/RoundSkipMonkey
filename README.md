# RoundSkipMonkey

A Bloons TD 6 mod that adds a special non-attacking Dart Monkey with an ability to select and jump to a chosen round.

## Features

- Adds a special Dart Monkey that does not attack Bloons.
- Lets you enter a round number from 1 to 9999.
- Uses the in-game ability to trigger the round selection.

## Installation

1. Install MelonLoader.
2. Install [BTD Mod Helper](https://github.com/gurrenm3/BTD-Mod-Helper).
3. Download `RoundSkipMonkey.dll` from the [latest release](https://github.com/Kamil2371/RoundSkipMonkey/releases/latest).
4. Place the DLL in your Bloons TD 6 `Mods` folder.
5. Launch the game.

## Compatibility

- Game: Bloons TD 6
- Requires: MelonLoader and BTD Mod Helper

This repository currently provides the compiled DLL release. Source project files are not included.
